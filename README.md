# HideUINames

A World of Warcraft: Forever addon that hides all unit name tags (players, NPCs,
guild names, PvP titles, pets, guardians, totems) while the UI is hidden
(Alt+Z), and restores your own name settings when the UI comes back.

Based on the Classic addon FlyCandy, rewritten to be safe on WoW: Forever
(no dependency on removed Interface Options frames; protected CVar calls; your
settings are saved before they are switched off).

## Install
Copy the `HideUINames` folder into `World of Warcraft\_forever_\Interface\AddOns\`.

## Use
Press Alt+Z. No settings, no commands.
